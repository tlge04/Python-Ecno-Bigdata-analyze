# 基于电商用户行为大数据的消费转化漏斗与购买预测分析

本项目是“Python 经济大数据分析”课程期末大作业，研究对象为电商平台用户行为日志，核心目标是回答四个问题：

1. 用户在浏览、加购、购买三个阶段上的总体行为结构是什么样的？
2. 2019 年 10 月、11 月、12 月之间的行为规模和转化效率有何差异？
3. 哪些品类、品牌和价格区间贡献了主要交易额？
4. 能否利用行为特征识别高购买倾向用户和高转化加购 session？

项目使用 Kaggle 数据集 `mkechinov/ecommerce-behavior-data-from-multi-category-store` 的 2019 年 10-12 月三个月数据，共处理 `177,493,621` 条日志，先完成全量行为聚合与转化漏斗分析，再构建两个机器学习任务：

- 用户-月份购买倾向识别
- 首次加购后的购物车转化预测

## 项目概览

这个项目不是单纯的统计图展示，也不是推荐系统项目。它的完整主线是：

1. 分块读取压缩 CSV，完成大规模行为日志清洗
2. 统计浏览、加购、购买三阶段的规模与漏斗结构
3. 分析月度变化、品类、品牌与价格带
4. 构造用户级和 session 级样本，做购买预测与转化排序
5. 将结果解释为电商运营中的转化诊断、用户分层和购物车召回支持

- 总日志数：`177,493,621`

- 估计购买用户：`1,045,680`

## 方法与实现

### 1. 数据处理

- 使用 `Pandas.read_csv(..., chunksize=1_000_000)` 分块读取压缩日志
- 统一解析时间字段，提取日期、小时、月份
- 清洗价格、品牌、品类和会话字段
- 在 chunk 内完成聚合，避免长期保存原始明细

### 2. 描述性分析

- 行为事件总量统计
- 月度、日度、小时维度变化
- 浏览-加购-购买三阶段漏斗
- 品类、品牌、价格区间结构分析

### 3. 机器学习部分

**模型一：用户购买倾向识别**

- 样本单位：用户-月份
- 标签：当月是否至少购买一次
- 用途：识别高购买倾向用户

**模型二：购物车转化预测**

- 样本单位：`user_session`
- 观察点：首次 `cart` 时刻
- 标签：首次加购后，session 内是否继续购买
- 训练测试划分：10-11 月训练，12 月测试
- 评估重点：`TopK / Lift`，用于解释营销排序价值

## 口径说明

- 事件规模、金额、时间变化、品类、品牌、价格带均基于三个月全量日志统计
- 唯一用户漏斗使用确定性抽样估计，不等同于全量精确去重
- 用户-月份模型是购买倾向识别，不夸大为严格实时预测
- 购物车转化模型只使用首次加购之前和首次加购当时可见的信息
- 高预测分数表示更可能自然购买，不等于最需要发券

## 项目边界

本项目适合解释为：

- 电商行为大数据处理
- 消费转化漏斗分析
- 用户购买倾向识别
- 购物车自然转化排序

本项目不直接声称：

- 推荐系统效果评估
- 促销因果识别
- 优惠券有效性证明

原因是数据中缺少曝光、优惠券、库存、物流等关键字段。
